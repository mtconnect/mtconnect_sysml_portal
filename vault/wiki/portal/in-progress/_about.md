# In Progress

> **Pattern: update-in-place** (see [SCHEMA.md §4](../../../SCHEMA.md#4-documentation-patterns)). This subfolder holds evolving notes about the version currently being built. Pages here are edited freely; on each meaningful edit the `updated:` date in frontmatter is bumped.

The version under development is **2.8**. When 2.8 ships:

1. The substantive content of these pages is summarized into a closing journal entry in [`../journal/`](../journal/).
2. Anything that should outlive the milestone (durable architecture notes, decisions) is promoted into the concept pages at [`../`](../).
3. This folder is reset for the next version.

See [SCHEMA.md §4 "Lifecycle of an in-progress subfolder"](../../../SCHEMA.md#lifecycle-of-an-in-progress-subfolder).
